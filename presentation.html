Pactopus MVP

The octopus-inspired way to make multi-chain invoicing feel human.

Pactopus is a playful invoicing app for freelancers, consultants, teams, and automation-friendly workflows. Create an invoice, share a link, get paid in USDC or EURC, and let the interface adapt in milliseconds to Arc or Algorand.

Why It Exists

Freelance invoicing is usually either too traditional, too technical, or both.

The old pain

  • Traditional invoicing feels disconnected from on-chain settlement.
  • Crypto payment apps often assume users already speak wallet-first jargon.
  • Multi-chain tools frequently behave like two separate products glued together.

The Pactopus answer

  • One invoice flow across supported chains.
  • One friendly voice for both technical and non-technical users.
  • One adaptive UI that visually matches the active blockchain workspace.
What It Does Today

Current product capabilities, no fairy dust required.

Create and share invoices

Users set amount, currency, description, recipient wallet, and optional recipient name, then share a payment link.

Verify payments server-side

Invoices are marked paid only after on-chain payment verification, reducing status spoofing risk.

Track everything in one dashboard

Balances, paid vs pending counts, recent invoices, and shareable links live in the same workspace.

User Journey

Friendly for newcomers, useful for experts, and weirdly charming in the right places.

For everyday users

  • Homepage explains the product in plain language.
  • Onboarding uses a conversational four-question guide.
  • Create, pay, and dashboard pages keep money-sensitive copy explicit and calm.

For delight without distraction

  • The navbar includes the exact toggle: 🐙 toggle the octofun!
  • OctoFun is off by default and never blocks payment actions.
  • Milestone toasts celebrate first wallet connect, first invoice, first payment, first dashboard visit, and a 30-day activity streak.
Technical Architecture

Implementation highlights for builders and judges.

Production stack

  • Next.js App Router with TypeScript & Turbopack.
  • Neon PostgreSQL with Prisma ORM and driver adapters.
  • TanStack Query for real-time data fetching and polling.
  • Token-driven responsive CSS design system.

Agentic payment rails

Pactopus natively equips autonomous AI agents with programmatic billing and liquidity management.

POST /api/v2/invoices - returns HTTP 402 Payment Required - verifies Arc USDC nanopayment on-chain - mints invoice upon ledger verification POST /api/v2/sweep - monitors agent wallet reserve float - sweeps surplus USDC into yield vault on Arc

Fully integrated: human freelancer invoicing and autonomous AI agent micro-billing under a single unified network.
