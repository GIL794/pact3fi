§ IV: Pillar 1

HTTP 402 Nanopayments

AI agents create invoices programmatically using HTTP 402. Every request is verified on-chain.

  • Unpaid request: Server returns 402 with billing headers.
  • Nano-transfer: Agent sends 0.05 USDC to target platform address.
  • RPC Validation: Server fetches receipt, validates logs, registers invoice.

§ VI: Pillar 3

Autonomous DeFi Yield Sweeper

A background worker monitors the agent wallet balance. To maximize capital efficiency, excess floats are swept into yield protocols.

  • Reserve Buffer: Always retains a 100 USDC gas buffer for operations.
  • ERC-4626 standard: Sweeps remaining balance into yield-bearing vaults on Arc L1.
// Sweeping excess USDC into Arc Vault:
const balance = await usdc.balanceOf(signer.address);
if (balance > reserveThreshold) {
  const sweepAmount = balance - reserveThreshold;
  // 1. Approve
  await usdc.approve(YIELD_VAULT_ADDRESS, sweepAmount);
  // 2. Deposit into vault
  await vault.deposit(sweepAmount, signer.address);
}
